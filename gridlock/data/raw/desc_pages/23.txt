Project Description 
Construct a 230 kV line with B1272 ACSR from Jasper to Okatie 230/115kV Substation. The line is 
estimated to be 6.5 miles long. This makes Jasper a Medium Impact substation and will require a new 
CIP Hut.  
 
Project Need 
This project is needed to improve system performance and to meet NERC TPL and internal DESC 
Planning Criteria for reliability.
